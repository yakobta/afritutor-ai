# AfriTutor Metaverse

This repository contains the AfriTutor Metaverse prototype: a decentralized, voice-native, AI-powered learning platform focused on immersive, low-bandwidth-first experiences for Pan-African learners.

This commit seeds the repo with the top-level architecture and build scripts. Subsequent commits will add modules for 3D/AR/VR, blockchain credentials, AI curriculum generation, social realtime, and offline-first PWA features.

Quick start (dev):
1. npm ci
2. npm run dev

See docs/ for architecture and integration guides.

## 🎯 What is AfriTutor AI?

**AfriTutor AI** is a context-aware, autonomous learning accelerator designed for students in resource-constrained African communities. Unlike traditional chatbots that struggle with language barriers and Western examples, AfriTutor AI delivers hyper-personalized, curriculum-aligned academic support using **code-switching** (English + Amharic + Kiswahili) and local examples from Kenya and Ethiopia.

---

## 🚀 The Problem We Solve

| Problem | Our Solution |
|---------|--------------|
| ❌ AI trained on Western examples (corn in Iowa) | ✅ Local examples (maize in Kenya, teff in Ethiopia) |
| ❌ English-only responses, students think in mother tongue | ✅ Code-switching (English + Amharic + Kiswahili) |
| ❌ High data usage, expensive for students | ✅ Text-first design, works on 2G/3G networks |
| ❌ One-size-fits-all explanations | ✅ Adaptive responses + instant quizzes |

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🎤 **Chat Interface** | Ask questions in English, Amharic, or Kiswahili |
| 🗣️ **Code-Switching** | AI responds mixing English with local languages |
| 📚 **Curriculum-Aligned** | Grade 10 Biology & Agriculture (Kenya & Ethiopia) |
| 🌿 **Local Examples** | Maize, teff, coffee, volcanic soils, Masai Mara |
| 📝 **Instant Quizzes** | Test understanding after each lesson |
| ⚡ **Low Data Mode** | Optimized for 2G/3G networks |
| 🌓 **Dark/Light Mode** | Comfortable for day or night study |
| 🎤 **Voice Input (Beta)** | Speak your questions instead of typing |
| 💾 **Local Storage** | Saves your preferences |
